# 高雄青職｜活力同行

這個 GitHub repository 只承載 GitHub Pages 前端與公開靜態資源。

- `html/`：使用者前端與管理頁面。
- `avatar-female/`、`avatar-male/`、`Chest_Assets/`、`Cute_Icons/`、`UI/`：網站使用的公開圖片資源。
- 根目錄的 `index.html` 與 `admin.html`：GitHub Pages 入口。

後端程式部署於 Google Apps Script，不在這個公開 repository 發布。玩家資料、密碼、Session、Token、試算表內容、Apps Script 私有屬性與本機測試資料不得加入 GitHub。
